# Support

## Current public scope

XMECK-AI 1.0.0.0 is published as an **engineering Founder candidate**.

The repository is suitable for:
- reviewing the product and engineering lineage;
- downloading the exact published candidate;
- validating hashes/manifests;
- reporting reproducible product defects.

## Before reporting a defect

Please include:
- product/build name;
- Windows version;
- relevant log/receipt name;
- exact reproduction steps;
- whether the local or connected route was active.

Do **not** post:
- API keys;
- access tokens;
- passwords;
- private project content;
- recovery secrets;
- private evidence archives.

## Release boundary

Trusted code signing and production update hosting remain external release holds.
The current candidate is not represented as a trusted signed commercial release.
