# XMECK-AI Public Architecture

![Architecture](../assets/diagrams/architecture.svg)

## Experience system
.NET 8 WPF on Windows x64.

## Product Truth
Canonical projection of ready / qualified / unavailable / held. UI presence alone does not establish readiness.

## Sovereign storage
Separates conversations/preferences, Projects, Knowledge metadata/indexes, user-imported models, credentials, diagnostics/evidence and historical state.

## Intelligence Hub
Managed GGUF lifecycle with explicit identity and runtime readiness.

## Capability Router
Local, connected and local artifact/tool routes remain explicit. Private/local mode does not silently fall back to cloud.

## Project Fabric
Local folder ownership, Git state, Knowledge association and work/evidence continuity.

## Work Modes
Ask, Research, Project, Build, Write.

## Agent Workforce
Bounded transitions; no ambient or self-approved authority.

## ProjectGuard
Protected-context egress and side-effect authority.

## Evidence
Receipts/evidence bind readiness, lifecycle and release claims to observable proof.

## Lifecycle
Install, repair, update, application-only uninstall, reinstall, explicit state removal, model/state preservation, deterministic package integrity, SBOM/provenance and recovery carrier.

## Release boundary
Signing-ready is not the same as trusted-signed. Trusted Publisher/signing and production update hosting remain external until proven.
