# XMECK-AI Public Visual System

## Palette
- Midnight / deep navy foundation
- Electric blue for intelligence / local runtime / navigation
- Orange for authority / transition / attention / release boundaries
- White / cool gray for product truth

## Visual language
- glass / layered surfaces;
- restrained orbital motion;
- technical diagrams that explain architecture rather than decorate it;
- current product screenshots as primary evidence;
- R1/R2 screenshots only inside Engineering Lineage;
- one strong current-product hero;
- explicit claim boundary visuals.

## README hierarchy
1. Premium hero
2. Product identity + motto
3. Product evolution
4. Current product surface
5. Projects/Git + managed intelligence
6. Engineering lineage gallery
7. Architecture
8. Market position
9. Evidence/claim boundary
10. Release/history policy
11. Ecosystem + citation

## Motion rule
Motion supports explanation. It must not make a capability look operational when it is only planned or simulated.
