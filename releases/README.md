# Releases

Use GitHub Releases for downloadable Windows artifacts.

Do not place model weights or large release binaries in the source tree.

A trusted public XMECK-AI release should include:
- qualified Windows installer / package;
- SHA-256 checksum file;
- release notes;
- capability and limitation boundary;
- trusted Publisher/signing evidence;
- public update/distribution authority where applicable.

The frozen Founder/engineering candidate is not automatically a trusted signed public release.
